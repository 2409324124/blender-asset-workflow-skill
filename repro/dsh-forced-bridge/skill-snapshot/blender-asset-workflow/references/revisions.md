# Revisions and reference calibration

Keep a read-only baseline copy and hash. Record the requested variant and exact changed parts before editing. A visually similar variant is not interchangeable; preserve user-approved dimensions, profile, attachments and stock/handle-like regions unless explicitly changed. A rollback means restoring that region from the specified baseline, not approximating its memory.

Use a small before/after table: part, change, preservation evidence, unresolved issue. Reuse the same cameras for comparison. A source hash remaining unchanged proves source preservation, not correct assembly of the copy.

## Only when reference matching is required
Distinguish orthographic drawings from perspective photos. Record orientation, datum and scale anchors. Use one uniform scale per view, never independently stretch horizontal and vertical axes to conceal mismatch. Unknown dimensions remain unknown; a photograph alone does not certify real-world dimensions.

Trace semantic silhouettes, not scan noise, grids, hidden guide lines, or decorative seams. Separate observed points, inherited values and derived/interpolated coordinates. A point table or SVG is useful when coordinate review matters, not mandatory for an original prop or scene. Multiple diagnostic views must derive from one 3D model, not independently drawn shapes.

Acceptance attaches to a particular baseline or image version. New work should preserve accepted regions and their assembly transforms. Existing defects remain labeled inherited rather than silently counted as new fixes.
