# v0.2 narrow post-test corrections — 2026-10-30

Frozen v0.1 remains separately preserved. Its independent café cold-test report and preview remain evidence for **v0.1 only**, not a v0.2 cold test. The first/final raw preview pixels show framing clipping followed by correction; those images alone do not establish that the bundled helper caused the initial framing error.

Changes and evidence:
- GLB inspection now resets to an empty factory scene before import instead of selection-based deletion. A regression starts with hidden, unselectable and collection-excluded stale meshes; only the two expected imported meshes remain.
- Timeout, termination grace and optional RSS limits reject NaN and ±Inf before launching any command. Nine invalid-limit combinations are checked, including a marker proving the child never ran.
- The descendant test now waits for a TERM-ignoring child to publish its PID, then inspects its real OS state after guard completion. Missing PID or terminated/zombie state is accepted, running/sleeping is not. This distinction avoids claiming a wrapper's completion proves child cleanup.
- White preview fitting uses projected bounds and the actual camera frame, including resolution and pixel aspect. Fifteen original long-cuboid direction/aspect combinations must place every bound corner inside the viewport with margin. This is a generic framing regression, not café-specific dimensions or a rerun of the original café.
- All earlier native/GLB roundtrip, hierarchy, world-matrix, bounds, PNG, source-hash, non-overwrite and runner checks retained.

Command: `python3 -m unittest discover -s tests -p 'test_*.py' -v`
Observed: **9 tests passed in 16.802 seconds**, Linux / Blender 4.3.2. Viewed the actual new 512 px neutral fixture preview: both parts are visible and unclipped. No beauty rendering, network assets, public upload, installation, or license activation.

Remaining limits are unchanged. Projected framing currently inventories visible meshes, not FONT/CURVE objects; the reference now explicitly says so. Independent visual judgment remains necessary. The strengthened descendant-state assertion is Linux-only. A terminated orphan zombie is not a live worker, and its eventual OS reaping is outside this direct-child runner's ownership.

Release-copy hygiene: removed PNG text/EXIF/time ancillary metadata from the local README café preview only. Decoded RGBA pixels are byte-identical to the original preview; the original cold-test image was not modified. No code or visible image content changed.
