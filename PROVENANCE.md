## Workflow and code

- Workflow concepts were generalized from the owner's earlier `blender-svg-refinement` and `cad-vehicle-motion-skills` work: accepted-baseline preservation, semantic reference calibration, articulation and actual-file verification. Historical project models, game integrations and domain-specific executable assets are not included.
- The reusable helpers, minimal-shop example and neutral regression fixtures were authored for this repository. The minimal shop is an author-provided procedural example, not an independent cold-context test.
- External Blender and Python software retain their own licenses. No external models, textures or real-company logos are required by the bundled example. External documentation links are references, not bundled third-party content.

## Tunguska iteration case

The model-only images under `docs/showcase/tunguska/` were generated during the owner-requested procedural exterior study and uploaded as case evidence, not an accepted realistic showcase. The two PNGs compare v03r1/v04 geometry; one JPEG compares two material iterations, and another shows read-only low-front/side shape diagnostics. No real-reference photo pixels, imported commercial meshes or external textures are bundled. These images follow the existing separately scoped showcase policy in [LICENSING.md](LICENSING.md); no new standalone redistribution license is asserted.

The [case note](docs/cases/tunguska-refinement.md) and [evidence summary](docs/cases/tunguska-evidence.json) record status, artifact hashes, source limitations and unverified photo attribution. The case does not certify dimensions, functionality or whole-vehicle resemblance. Native models/full build scripts and third-party reference photographs remain outside this documentation change.
