## Workflow and code

- Workflow concepts were generalized from the owner's earlier `blender-svg-refinement` and `cad-vehicle-motion-skills` work: accepted-baseline preservation, semantic reference calibration, articulation and actual-file verification. Historical project models, game integrations and domain-specific executable assets are not included.
- The reusable helpers, minimal-shop example and neutral regression fixtures were authored for this repository. The minimal shop is an author-provided procedural example, not an independent cold-context test.
- External Blender and Python software retain their own licenses. No external models, textures or real-company logos are required by the bundled example. External documentation links are references, not bundled third-party content.
